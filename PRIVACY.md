# Privacy Policy

**7 30**  
A SYNC project.

Last updated: October 8, 2026.

## Overview

7 30 is a Discord bot that plays scheduled audio events at 07:30 and 19:30 according to a timezone selected for each Discord server.

The bot is designed to collect and retain only the information required for this functionality.

## Data stored

7 30 stores:

- the Discord server ID;
- the timezone selected for that server.

This information is stored only for configuration and scheduling purposes.

## Data processed during operation

To provide its functionality, 7 30 may temporarily process Discord metadata such as:

- server names;
- channel names and IDs;
- voice channel information;
- Discord permission information.

This information is used to register commands, select a setup channel, connect to voice channels, and operate scheduled playback.

It is not stored as part of the persistent server configuration unless specifically described above.

## Operational logs

Operational logs may contain:

- server names;
- channel names;
- configured timezones;
- playback status;
- technical error information.

Logs are used for operation and troubleshooting and are retained according to the log rotation policy of the system hosting the bot.

## Data not collected

7 30 does not intentionally store:

- Discord message content;
- direct messages;
- voice conversations or voice recordings;
- passwords;
- Discord user authentication credentials.

The bot token used to operate 7 30 is stored privately by the operator and is not part of the public repository.

## Data retention and deletion

Server configuration is retained while 7 30 remains installed in that Discord server.

When the bot is removed from a server, its stored configuration is deleted.

The bot also removes stale server configuration during startup when the corresponding Discord server is no longer available to it.

## Third-party services

7 30 relies on Discord and the Discord API to operate.

Use of Discord is subject to Discord's own terms and privacy policies.

## Sale of data

7 30 does not sell user or server data.

## Security

Reasonable technical measures are used to limit stored information and keep credentials separate from the public source code.

No system can guarantee absolute security.

## Changes to this policy

This Privacy Policy may be updated when the bot's functionality or data handling changes.

The current version will remain available in the public project repository.

## Contact

Questions about this Privacy Policy can be submitted through the GitHub repository for 7 30.

Do not include passwords, tokens, API keys, or other secrets in public issues.
